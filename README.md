# College Placement System

A web-based **College Placement System** designed to simplify and centralize the college placement process for students, placement coordinators, and recruiters.

## 📌 Overview

The College Placement System provides a single platform where students can maintain their profiles, view available placement drives, and check their eligibility based on academic and placement criteria.

The system helps placement coordinators manage recruitment drives, student information, eligibility requirements, and placement-related activities in an organized manner.

## 🎯 Objectives

* Centralize college placement information in one platform.
* Allow students to create and manage their placement profiles.
* Display upcoming and ongoing placement drives.
* Automatically check student eligibility for different companies.
* Reduce manual work for placement coordinators.
* Make the placement process more organized and transparent.
* Maintain placement-related data securely and efficiently.

## ✨ Key Features

### 👨‍🎓 Student Module

* Student registration and login
* Student profile management
* Academic information management
* View available placement drives
* Check eligibility for companies
* Apply for eligible placement opportunities
* Track application/placement status

### 🏢 Placement Drive Module

* Create and manage placement drives
* Add company details
* Define eligibility criteria
* Set application deadlines
* View eligible students
* Manage drive-related information

### ✅ Eligibility Checking

The system can determine whether a student is eligible for a placement drive based on criteria such as:

* Branch
* CGPA
* Graduation year
* Backlogs
* Other company-specific requirements

### 📊 Placement Management

* Track student applications
* Manage shortlisted students
* Maintain placement records
* View placement-related information
